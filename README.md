# HydroCrack Insight

HydroCrack Insight - desktop-прототип автоматизированной системы мониторинга и
управления процессом гидрокрекинга в нефтехимической промышленности.

Проект развивается по техническому заданию из ЛР5. ЛР1-ЛР4 используются как
вспомогательные материалы для понимания предметной области, процессов и моделей.

## Назначение

Система предназначена для:

- мониторинга технологических параметров установки;
- анализа отклонений от технологических ограничений;
- формирования рекомендаций оператору и технологу;
- аварийного реагирования на уровне демонстрационной модели;
- учета ресурсов;
- прогнозирования результатов процесса;
- формирования отчетности.

## Текущее состояние

Сейчас реализован ранний MVP desktop-приложения:

- PyQt6-интерфейс с вкладками мониторинга, оборудования, отклонений, отчетов и
  журнала;
- программная имитация данных датчиков вместо реальной SCADA/DCS-интеграции;
- вход в систему под демо-пользователями с ролями из ТЗ;
- ограничение вкладок и оперативных действий по текущей роли;
- смена пользователя без перезапуска приложения;
- восстановление последних событий, отклонений и статусов оборудования из общей
  БД при входе другой роли;
- таблица технологических параметров с нормами, единицами измерения и статусами;
- live-графики трендов ключевых параметров;
- импорт CSV/Excel-файлов с технологическими параметрами;
- выбор активного технологического режима и проверка параметров по его уставкам;
- вкладка учета ресурсов со сменными и суточными агрегатами, лимитами и статусом перерасхода;
- сменный журнал с записями оператора и фиксацией передачи смены по чек-листу;
- анализ отклонений по температуре, давлению и расходу водорода;
- демонстрационная аварийная логика и изменение статусов оборудования;
- сохранение параметров, отклонений, событий, аудита и статусов оборудования в
  SQLite.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

Демо-пользователи: `operator`, `technologist`, `instrumentation`, `manager`,
`admin`. Пароль для всех демо-учеток: `demo`.

Для импорта CSV используйте колонки `timestamp`, `temperature`, `pressure`,
`feed_flow`, `hydrogen_flow`. Дополнительно можно указать `energy`,
`water_consumption`, `catalyst_consumption`, `product_yield`, `mode`, `status`.
Для Excel-файлов нужен пакет `openpyxl`.

## Проверка

Базовые проверки ядра приложения можно запустить без старта PyQt-интерфейса:

```powershell
python -m unittest discover -s tests
```

Также полезна синтаксическая проверка проекта:

```powershell
python -m compileall -q .
```
