# План разработки HydroCrack Insight

Основной ориентир - техническое задание из ЛР5. Приложение развивается как
desktop-система на Python и PyQt.

## 0. Подготовка проекта

Цель: развернуть репозиторий локально, создать безопасную ветку разработки и
подготовить базовые проверки.

Критерии готовности:

- код находится в рабочей папке проекта;
- создана ветка `desktop-tz5-development`;
- README описывает desktop-формат, установку, запуск и проверки;
- добавлены документы с планом и покрытием требований;
- есть baseline-тесты для ключевой доменной логики;
- синтаксическая проверка и baseline-тесты проходят.

## 1. Приведение структуры к ТЗ

Цель: явно разделить приложение на подсистемы из ЛР5.

Работы:

- уточнить пакеты для мониторинга, оборудования, ресурсов, отчетов,
  прогнозирования, пользователей и журналирования;
- выделить сервисы предметной области отдельно от UI;
- зафиксировать термины проекта: установка, оборудование, датчик, режим,
  отклонение, рекомендация, отчет.

## 2. База данных

Цель: приблизить хранилище к IDEF1X/UML-модели и требованиям ЛР5.

Работы:

- расширить SQLite-схему таблицами пользователей, ролей, установок, оборудования,
  датчиков, показаний, планов, ресурсов, рекомендаций и отчетов;
- добавить загрузку последнего состояния после перезапуска;
- подготовить слой доступа к данным так, чтобы позднее можно было перейти на
  PostgreSQL без полной переписи UI.

## 3. Пользователи и роли

Цель: реализовать разграничение функций по ролям.

Роли:

- оператор;
- технолог;
- инженер КИПиА/АСУ ТП;
- руководитель;
- администратор.

Работы:

- добавить экран входа;
- ограничить вкладки и действия в зависимости от роли;
- журналировать входы и значимые операции.

## 4. Мониторинг и тренды

Цель: довести мониторинг до уровня демонстрации технологического режима.

Работы:

- добавить таблицу параметров с единицами измерения, нормами и статусами;
- добавить графики трендов;
- улучшить симулятор источника данных;
- добавить импорт CSV/Excel как учебную замену интеграции с SCADA/DCS.

## 5. Режимы и технологические ограничения

Цель: перейти от захардкоженных порогов к справочнику режимов.

Работы:

- добавить режимы: мягкий, нормальный, жесткий, максимум керосина,
  энергосберегающий;
- хранить диапазоны параметров для активного режима;
- классифицировать отклонения как незначительные, существенные и критические;
- журналировать изменение режимов и уставок.

## 6. Журналы

Цель: покрыть журнал событий, сменный журнал и передачу смены.

Работы:

- добавить сменный журнал;
- добавить чек-лист передачи смены;
- добавить комментарии к отклонениям и действиям;
- добавить фильтры по времени, типу, важности и оборудованию.

## 7. Ресурсы

Цель: реализовать учет расхода ресурсов.

Работы:

- учитывать водород, энергию, воду, катализатор и реагенты;
- показывать расход за смену и сутки;
- выявлять перерасход;
- связывать ресурсные показатели с режимом и планом.

## 8. Прогнозирование и оптимизация

Цель: добавить расчетный модуль для оценки сценариев.

Работы:

- вынести расчет выхода продукции в отдельный сервис;
- добавить сценарии изменения температуры, давления, расхода сырья и водорода;
- показывать сравнение текущего и прогнозного результата;
- формировать рекомендации без прямого вмешательства в контуры DCS/PLC.

## 9. Отчетность

Цель: заменить заглушки настоящими отчетами.

Работы:

- сформировать сменный отчет;
- сформировать суточный отчет;
- сформировать отчет по отклонениям и авариям;
- сформировать отчет по ресурсам;
- добавить экспорт PDF и CSV/Excel.

## 10. Диагностика и надежность

Цель: показать устойчивость и контролируемость системы.

Работы:

- добавить экран диагностики источника данных;
- отображать статус БД, симулятора и последнего обновления;
- добавить резервное копирование SQLite;
- обработать ошибки без падения приложения.

## 11. Финальная доводка

Цель: подготовить проект к демонстрации и защите.

Работы:

- расширить unit-тесты;
- добавить smoke-сценарий запуска;
- наполнить систему демо-данными;
- обновить README и пользовательскую инструкцию;
- подготовить список реализованных требований ЛР5.
