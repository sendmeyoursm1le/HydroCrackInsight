# Реализованные требования ЛР5

## Мониторинг

- Отображение технологических параметров установки гидрокрекинга.
- Генерация учебных данных вместо реального подключения к SCADA/DCS.
- Live-графики ключевых параметров.
- Сохранение истории процесса и показаний датчиков в SQLite.
- Импорт CSV/Excel-файлов с технологическими параметрами.

## Отклонения и аварии

- Проверка параметров по уставкам активного технологического режима.
- Предупреждения и аварийные состояния.
- Рекомендации оператору/технологу.
- Демонстрационное изменение статусов оборудования.
- Аварийная остановка выпуска продукции при критических параметрах.

## Режимы и прогнозирование

- Справочник технологических режимов.
- Выбор активного режима технологом/администратором.
- Отображение цели режима и его уставок.
- Сценарное прогнозирование выхода продукции.
- Рекомендации по простым сценариям оптимизации.

## Ресурсы

- Учет водорода, электроэнергии, охлаждающей воды и катализатора.
- Сменные и суточные агрегаты.
- Лимиты и статус перерасхода.

## Журналы

- Журнал событий.
- Журнал отклонений.
- Сменный журнал.
- Итог смены с чек-листом.
- Аудит входов и значимых действий пользователя.

## Отчетность

- Суточный отчет.
- Отчет по ресурсам.
- Отчет по авариям и отклонениям.
- Сменный отчет.
- Экспорт отчетов в PDF.
- История сформированных отчетов в БД.

## Пользователи и роли

- Вход в систему.
- Демо-пользователи для всех ролей из ТЗ.
- Разграничение вкладок и действий по ролям.
- Смена пользователя без перезапуска приложения.

## Диагностика и надежность

- Экран диагностики состояния БД и симулятора.
- Проверка обязательных таблиц и версии схемы.
- Отображение последних измерений и событий.
- Резервное копирование SQLite для администратора.

## Ограничения учебного прототипа

- Нет реального подключения к промышленной SCADA/DCS.
- Нет прямого управления PLC/DCS.
- Нет полноценного управления учетными записями и политиками доступа.
- Нет восстановления БД из backup через интерфейс.
- Отчеты имеют базовый шаблон без настройки периодов.
