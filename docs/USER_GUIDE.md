# Пользовательская инструкция

## Запуск

1. Откройте папку проекта в VS Code.
2. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

3. Запустите приложение:

```powershell
python main.py
```

## Демо-пользователи

Пароль для всех учетных записей: `demo`.

| Логин | Роль | Назначение |
| --- | --- | --- |
| `operator` | Оператор | Мониторинг, оборудование, журнал и итог смены, оперативные действия |
| `technologist` | Технолог | Режимы, прогнозы, отчеты, анализ отклонений |
| `instrumentation` | Инженер КИПиА/АСУ ТП | Оборудование, диагностика, технические записи |
| `manager` | Руководитель | Просмотр KPI, ресурсов, прогнозов и отчетов |
| `admin` | Администратор | Все разделы, пользователи, диагностика и резервные копии |

## Основные сценарии показа

1. Войти под `operator`.
2. На вкладке **Мониторинг** запустить мониторинг и посмотреть изменение параметров.
3. Нажать **Сымитировать аварию** и показать аварийный статус, изменение оборудования и остановку выпуска продукции.
4. На вкладке **Ресурсы** показать сменный и суточный расход.
5. На вкладке **Сменный журнал** добавить запись и зафиксировать итог смены.
6. Сменить пользователя на `technologist`.
7. На вкладке **Прогноз** рассчитать сценарии оптимизации.
8. На вкладке **Отчеты** сформировать суточный, ресурсный, аварийный или сменный отчет.
9. Войти под `admin` и на вкладке **Диагностика** создать резервную копию БД.

## Демо-данные

Для быстрого наполнения базы учебными данными выполните:

```powershell
python scripts/seed_demo_data.py
```

Скрипт создаст события, отклонение, сменный журнал, итог смены и демо-отчеты.

## Smoke-проверка

Перед защитой можно выполнить быструю проверку ролей, вкладок и запуска главного окна:

```powershell
python scripts/smoke_check.py
```

Ожидаемый результат: `Smoke-check пройден`.
